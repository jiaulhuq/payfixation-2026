# Pay Fixation 2026 — V1

GitHub Pages-ready calculator for Bangladesh National Pay Scale 2026.

## Files
- index.html — interface
- style.css — responsive design
- script.js — calculation engine
- data.js — 2015 and 2026 grade/step data

## GitHub Pages
1. Create a new GitHub repository, e.g. `payfixation-2026`.
2. Upload all four files to the repository root.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/root`.
5. Save and wait for deployment.
6. Open `https://YOUR-USERNAME.github.io/payfixation-2026/`.

## Important
This V1 implements the core Article 5 difference-method calculation and Article 9(2) increment logic, plus the staged 2026 implementation percentages.
The 2028 allowance section deliberately keeps some values editable rather than inventing rates. Verify all allowance rates against the applicable official gazette/office order before operational use.

This is an independent helper tool, not an official iBAS++ service.
